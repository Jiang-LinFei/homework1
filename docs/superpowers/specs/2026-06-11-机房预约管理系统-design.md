# 机房预约管理系统 — 设计文档

- 日期：2026-06-11
- 分支：`cgx`（Jiang-LinFei/homework1）
- 方向：机房预约 / 排课（按课表或时间段预约机房/机位、审批、占用日历）

## 1. 目标与范围

构建一个**前后端分离**的机房预约管理系统，替换 cgx 现有的 Django 模板单体项目。

v1 功能（全部保留）：

1. 角色：管理员 / 教师 / 学生（JWT 登录）
2. 机房 & 机位管理（管理员维护：机房、容量/机位、开放时段）
3. 预约：按「时间段」或「课表节次」预约整间机房或指定机位，自动冲突检测
4. 审批流：学生/教师提交 → 管理员（或教师）审批通过/驳回
5. 占用日历：按机房看每天/每周的占用情况（日历视图）
6. 课表 / 排课：管理员给机房排固定课程（周期性占用）
7. 仪表盘：预约统计图表（数量 / 通过率 / 机房利用率）

非目标（YAGNI，v1 不做）：在线支付、消息推送/邮件、多校区/多租户、移动端 App、复杂权限矩阵（仅三种固定角色）。

## 2. 技术栈（固定）

后端：Python 3.10.11 / Django 3.2.25 / DRF 3.14 / MySQL 5.7.44 / Redis（缓存 + JWT 黑名单）
前端：Node.js 20 LTS / Vue 3.4.38 / Vite 5.4.14 / Element Plus / FullCalendar / Pinia / vue-router / axios
设计：ui-ux-pro-max 提供配色/排版/UX 规范，全中文界面
部署：Docker Compose（CentOS 8 / 宝塔宿主）

## 3. 架构

```
┌─────────────────────────┐        ┌──────────────────────────────┐
│ frontend                │  /api  │ backend                      │
│ Vue3+Vite 打包产物      │ ─────▶ │ Django3.2 + DRF (gunicorn)   │
│ 由 Nginx 托管 + 反代    │        │  ├─ MySQL 5.7  (数据)         │
└─────────────────────────┘        │  └─ Redis      (缓存/黑名单)  │
                                    └──────────────────────────────┘
```

四个容器：`db`(mysql:5.7)、`redis`(redis:7)、`backend`(Django+gunicorn)、`frontend`(nginx 托管 Vite 产物并反代 `/api`→backend)。开发期 db/redis 用 Docker，后端用 pyenv 3.10.11 本地跑，前端 `vite dev`。

## 4. 数据模型

### accounts.User（继承 AbstractUser）
| 字段 | 类型 | 说明 |
|---|---|---|
| username / password | — | Django 自带 |
| name | Char | 真实姓名 |
| role | Char(choices) | `admin` / `teacher` / `student` |
| phone | Char(可空) | 联系电话 |

### rooms.Room 机房
| 字段 | 类型 | 说明 |
|---|---|---|
| name | Char | 机房名（如 实训楼301） |
| location | Char | 位置 |
| capacity | Int | 容量（机位数） |
| open_time / close_time | Time | 每日开放时段 |
| status | Char(choices) | `open` / `closed` / `maintenance` |
| description | Text(可空) | 备注 |

### rooms.Seat 机位
| 字段 | 类型 | 说明 |
|---|---|---|
| room | FK→Room | 所属机房（级联删除） |
| code | Char | 机位编号（机房内唯一） |
| status | Char(choices) | `available` / `maintenance` |

### rooms.TimeSlot 节次
| 字段 | 类型 | 说明 |
|---|---|---|
| name | Char | 如「第1-2节」 |
| start_time / end_time | Time | 时间范围 |
| order | Int | 排序 |

### bookings.Booking 预约
| 字段 | 类型 | 说明 |
|---|---|---|
| applicant | FK→User | 申请人 |
| room | FK→Room | 机房 |
| seat | FK→Seat(可空) | 为空=预约整间机房 |
| date | Date | 预约日期 |
| timeslot | FK→TimeSlot(可空) | 二选一：按节次 |
| start_time / end_time | Time(可空) | 二选一：自定义时间段 |
| purpose | Char | 用途 |
| status | Char(choices) | `pending` / `approved` / `rejected` / `cancelled` |
| reviewer | FK→User(可空) | 审批人 |
| review_comment | Char(可空) | 审批意见 |
| reviewed_at | DateTime(可空) | 审批时间 |
| created_at | DateTime | 创建时间 |

**冲突检测规则**（提交/审批通过时校验）：同一 `room`（若指定 `seat` 则同一 `seat`）、同一 `date`、时间区间重叠，且对方状态为 `approved`（排课同理参与），则视为冲突。整间预约与该机房任意机位预约互斥。

### schedules.Schedule 排课
| 字段 | 类型 | 说明 |
|---|---|---|
| room | FK→Room | 机房 |
| course_name | Char | 课程名 |
| teacher | FK→User | 任课教师 |
| weekday | Int(1-7) | 星期几 |
| timeslot | FK→TimeSlot | 节次 |
| start_week / end_week | Int | 起止周（周期性占用） |

排课展开为周期性占用，参与预约冲突检测与占用日历显示。

## 5. 后端 API（DRF + SimpleJWT）

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/api/auth/login` | 登录拿 access/refresh | 公开 |
| POST | `/api/auth/refresh` | 刷新 token | 公开 |
| POST | `/api/auth/logout` | 注销（refresh 入黑名单） | 登录 |
| GET | `/api/auth/me` | 当前用户信息 | 登录 |
| CRUD | `/api/users` | 用户管理 | admin |
| CRUD | `/api/rooms` | 机房管理 | 读=登录，写=admin |
| CRUD | `/api/seats` | 机位管理 | 读=登录，写=admin |
| CRUD | `/api/timeslots` | 节次管理 | 读=登录，写=admin |
| CRUD | `/api/bookings` | 预约（list 按角色过滤） | 登录 |
| POST | `/api/bookings/{id}/approve` | 通过 | admin/teacher |
| POST | `/api/bookings/{id}/reject` | 驳回 | admin/teacher |
| POST | `/api/bookings/{id}/cancel` | 取消（本人） | 登录 |
| CRUD | `/api/schedules` | 排课 | 读=登录，写=admin |
| GET | `/api/calendar?room=&start=&end=` | 占用日历（预约+排课合并） | 登录 |
| GET | `/api/stats/dashboard` | 仪表盘统计 | 登录 |

鉴权：`djangorestframework-simplejwt`，access/refresh + Redis 黑名单。权限用 DRF 的 `IsAuthenticated` + 自定义角色权限类。

## 6. 前端

- 组件库 Element Plus（中文友好，自带表格/表单/分页/日历）；占用日历用 `@fullcalendar/vue3`。
- ui-ux-pro-max 输出配色/字体/间距等设计 token，统一注入到 Element Plus 主题与全局样式。
- 状态 Pinia（auth/user）、路由 vue-router（路由守卫按角色控制可见菜单）、axios 拦截器自动带 JWT 与刷新。
- 页面：登录、仪表盘(ECharts/Chart 图表)、机房管理、机位管理、节次管理、排课、预约日历(占用)、我的预约/申请预约、审批管理、用户管理。

## 7. 部署（Docker Compose）

- `docker-compose.yml`：db(mysql5.7, utf8mb4)、redis、backend(gunicorn, 收集静态, migrate, 初始化演示数据)、frontend(多阶段构建 vite→nginx)。
- `.env.example`：DB/Redis/SECRET_KEY/允许域名等。
- 前端 Nginx 托管 SPA 并反代 `/api`→backend，处理 history 路由 fallback。
- 一键：`docker compose up -d --build`。交付到用户本地 `d:\project\cgx\homework1`，由用户在 CentOS 8/宝塔本地用 Docker 运行。
