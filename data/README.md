# 数据说明

## 完整数据集 (训练时自动下载)
- **METR-LA**: 洛杉矶都会区 207 个环形检测器在 2012.03–2012.06 期间采集的交通速度数据,
  每 5 分钟一个采样点,共 34272 个时间步。
- 由 PyTorch Geometric Temporal 的 `METRLADatasetLoader` 自动下载到本目录
  (`METR-LA.zip` / `node_values.npy` / `adj_mat.npy`),这些大文件已在 `.gitignore` 中忽略。

## 仓库内提交的部分数据 (`data/sample/`)
满足作业"提交部分数据"的要求:
- `node_values_sample.npy` — 形状 `[2016, 207, 2]`,即前约 1 周(2016 个 5-min 时间步)、
  207 个传感器、2 个特征(车速 + 一天内时刻)。
- `adj_mat.npy` — 形状 `[207, 207]`,路网邻接矩阵(基于传感器间路网距离的高斯核权重),
  用于构建图结构。

## 字段含义
- 第 0 个特征:车速(单位 mph,取值约 0–70)。样本文件保存的是原始尺度,
  z-score 归一化由 `METRLADatasetLoader` 在加载阶段统一完成。
- 第 1 个特征:归一化的"一天中的时间"(time-of-day),用于刻画周期性。
- 邻接矩阵权重越大表示两个传感器在路网上越近、关联越强。
