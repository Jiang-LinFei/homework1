学生课程小组作业系统 

说明：这是按实际点一遍系统写出来的流程，照着做就能把主要功能都走通。


一、先启动程序
----------------
1. 打开命令行，进项目目录 d:\project\wuqiqiqiqi
2. 运行：java -jar target\student-course-team-system-1.0.0.jar
3. 弹出登录窗口


二、登录
--------
1. 输入学号（就是用户名），比如 2021001
2. 输入密码，测试账号都是 123456
3. 点「登录」

能用的测试号：
- 2021001 陈同学（第2组组长，推荐用这个体验完整功能）
- 2021002 李同学（第1组组长）
- 2021003 王同学
- 2021004 赵同学
- 2021005 刘同学（只选了「数据库原理」这门课，课程列表和别人不一样）


三、登录后的主页
----------------
进来之后你会看到三块：

【我的课程】
- 上面一排蓝色按钮，是你选过的课
- 点课程名进去，能看到这门课的小组情况

【我的课程小组】
- 左边列表，你已经加入的小组
- 点一下某一行，直接进入那个小组的讨论区

【消息通知】
- 右边列表，课程公告、邀请、申请结果都会在这里
- 下面有个「处理邀请/申请」按钮，有 pending 的消息时点它，选一条，同意或拒绝


四、进课程 → 创建或加入小组
----------------------------
1. 主页点「管理信息系统」这类课程按钮
2. 进来能看到：
   - 「创建小组」：你当组长，输入小组名，再填组员学号（逗号隔开），系统会给对方发邀请
   - 「加入小组」：选还没加入的小组，发申请，等组长同意
3. 「我已加入的小组」点一行就能进小组
4. 左上角「返回主页」回去


五、小组里面（核心界面）
------------------------
左边深蓝导航栏：
- 讨论区：看聊天记录、发消息
- 文件管理：看谁传了啥文件
- 任务管理：看小组任务进度，选中一行再点「更新选中任务状态」
- 上传文件：选本地文件上传到小组
- 提交作业：填标题说明，选文件，算一次作业提交
- 返回主页：回首页

中间大区域跟着左边切换。

右边：
- 小组成员（组长会标出来）
- 课程公告


六、典型协作流程（建议演示顺序）
--------------------------------
用两个号交替登录更好演示：

【场景1：聊天】
陈同学 2021001 登录 → 主页点「管理信息系统 · 第2组」→ 讨论区打字 → 点发送

【场景2：看任务 / 改状态】
还在小组里 → 点「任务管理」→ 表格里点选一条 → 「更新选中任务状态」→ 选新状态

【场景3：传文件】
点「上传文件」→ 选文件 → 上传成功可以选去看文件列表

【场景4：组长建群拉人】
换 2021002 登录 → 进「管理信息系统」→ 创建小组 → 填组名、填 2021003 → 成功
换 2021003 登录 → 主页「处理邀请/申请」→ 同意 → 主页小组列表里能看到新组

【场景5：主动申请加群】
换 2021004 登录 → 进课程 → 加入小组 → 选「第1组」→ 申请
换 2021002 登录（第1组组长）→ 处理申请 → 同意
再换 2021004 看，已经在组里了

【场景6：退出登录】
主页右上角「退出登录」


七、验收对照（对应课程需求）
----------------------------
✓ 学号密码登录，数据走 SQL
✓ 不同学生课程/小组不一样
✓ 主页有小组列表 + 消息通知
✓ 课程里能创建小组、加入小组
✓ 邀请/申请/同意/拒绝 流程完整
✓ 小组内有聊天、任务、文件、作业提交
✓ 界面三栏布局，风格统一


八、测试过程中修过的问题
------------------------
1. 加入申请在通知里显示成组长名字 → 已改成显示申请人
2. 左侧栏课程名写死「管理信息系统」→ 已改成跟实际课程走
3. 任务更新要手输行号 → 已改成选中表格行再更新
4. 上传完不知道去哪看 → 上传成功会提示是否跳转文件列表
5. 加入小组列表包含已加入的组 → 已过滤掉
6. 重复邀请在列表里出现两次 → 已去重
7. 【严重】数据库 init.sql 被重复执行 → 消息/任务/通知会越积越多，发空消息也像“多发了几条”。已修复，首次启动后只初始化一次
8. 非小组成员也能读聊天 → 已加权限校验，非成员读/发消息会提示错误
9. 初始数据里刘同学不在第1组但挂在组里 → 已修正 seed 数据

九、GUI 逐步验收（真实启动界面，31步）
------------------------------------
这条才是「启动项目、一项一项点过去」的验收，会真的弹出 Swing 窗口并在 EDT 上模拟点击。

运行命令：
mvn test-compile exec:java "-Dexec.mainClass=com.mis.team.ui.GuiStepByStepRunner" "-Dexec.classpathScope=test"

走查顺序（全部自动执行，控制台会逐步打印 PASS/FAIL）：
01 启动登录窗 → 02 错密码 → 03 正确登录进主页 → 04~05 看小组/通知
06 点课程 → 07~08 看小组列表 → 09 进第2组讨论区
10~12 看标题/成员/历史消息 → 13 发消息 → 14 空消息不发
15~17 任务管理+改状态 → 18~21 文件管理+上传 → 22~23 提交作业
24 回讨论区 → 25 回主页 → 26 创建小组拉人 → 27 退出
28 换王同学同意邀请 → 29 换赵同学申请入组 → 30 换李组长同意 → 31 关窗

当前结果：31/31 全部通过。

十、后台严格验收（70项，不弹窗）
--------------------------
运行命令：
mvn test-compile exec:java "-Dexec.mainClass=com.mis.team.StrictAcceptanceTestRunner" "-Dexec.classpathScope=test"

覆盖范围：
- 登录（5项）：正确/错误密码/不存在学号/空输入
- 课程主页（11项）：不同学生不同课、小组列表、通知、未读数
- 课程小组（4项）：我的组/全部组/组长信息
- 成员（3项）：人数、姓名、组长角色
- 讨论区发消息（13项）：历史记录、发送者、自己/他人气泡、排序、发送/空消息/空白/裁剪、他人可见、持久化、多人互发
- 任务（8项）：列表、字段、改状态、新增、作业提交
- 文件（4项）：入库、磁盘存在、上传者、多次上传
- 建组邀请（8项）：组长入组、发邀请、通知、无效学号、不邀自己、接受、拒绝、越权
- 申请加入（9项）：组长收到、通知、重复拦截、已在组拦截、同意、拒绝、非组长不能审
- 权限边界（5项）：非成员不能读/发消息、邀请状态、标记已读

当前结果：70/70 全部通过。
